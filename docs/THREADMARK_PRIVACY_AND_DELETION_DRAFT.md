이 문서는 ThreadMark의 개발 및 제한적 테스트 단계에서 사용할 개인정보 처리방침과 데이터 삭제 절차 초안이다. 공개 서비스로 전환하기 전에 실제 구현, 이용 대상, 외부 서비스의 최신 약관, 개인정보의 국외 이전 세부사항 및 대한민국 관련 법령을 다시 검토해야 한다. 이 초안은 법률 자문을 대신하지 않는다.

## 1. 서비스 운영 방식

ThreadMark는 연구, 수업, 독서 및 일상에서 발견한 자료와 생각을 Source, Capture, Project 단위로 저장하고 연결하는 개인 지식 관리 서비스다.

초기에는 회원가입 후 관리자의 승인을 받은 사용자만 이용할 수 있다. `신규 가입 승인 필요` 설정이 켜진 동안 신규 계정은 승인 대기 상태가 되며, 관리자가 승인하기 전에는 개인 자료 저장 기능에 접근할 수 없다. 향후 이 설정을 끄면 그 이후의 신규 가입자는 자동 승인될 수 있다. 설정을 끄더라도 이미 승인 대기 중인 계정은 자동으로 승인되지 않는다.

ThreadMark는 서비스 제공에 필요한 범위에서 다음 정보를 처리할 수 있다.

## 3. Google Drive 데이터 사용

ThreadMark는 Google Drive 전체 접근 권한 대신 `https://www.googleapis.com/auth/drive.file` 범위를 사용한다. 이에 따라 사용자가 ThreadMark를 통해 만들거나 Google Picker로 명시적으로 선택한 파일을 중심으로 접근한다.

- 사용자의 Drive 파일 자체는 원칙적으로 사용자의 Google Drive에 저장된다.
- ThreadMark 데이터베이스에는 파일을 다시 찾기 위한 ID와 최소한의 메타데이터를 저장할 수 있다.
- 비공개 Drive 파일을 자동으로 공개 링크로 변경하지 않는다.
- Google refresh token은 서버 전용 영역에 암호화하여 저장한다.
- Google 사용자 데이터는 사용자에게 보이는 파일 연결·열기·저장 기능을 제공하는 목적으로만 사용한다.
- Google 사용자 데이터를 판매하거나 광고, 신용평가 또는 데이터 중개 목적으로 사용하지 않는다.
- 운영자는 사용자의 명시적 동의, 보안 사고 조사 또는 법적 의무가 있는 경우를 제외하고 사용자의 Drive 파일 내용을 임의로 열람하지 않는다.

**Google Limited Use 고지:** ThreadMark의 Google API에서 수신한 정보의 사용 및 다른 앱으로의 전송은 Limited Use 요건을 포함한 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)를 준수한다.

## 4. 생성형 AI 사용

ThreadMark는 Anthropic Claude API를 부분 번역, 짧은 요약, 키워드·태그 후보 및 연구·수업 아이디어 생성에 사용할 수 있다.

- 사용자가 AI 기능을 명시적으로 실행한 경우에만 선택된 텍스트를 전송한다.
- PDF 전체 또는 Google Drive 파일 전체를 자동으로 전송하지 않는다.
- AI 요청 직전에 전송 범위와 목적을 사용자가 확인할 수 있게 한다.
- AI 생성 결과는 원문 및 사용자 작성 내용과 구분한다.
- 광고 또는 범용 AI 모델 학습을 목적으로 Google 사용자 데이터를 제공하지 않는다.
- 실제 공개 전 Anthropic의 당시 데이터 보존·학습 설정과 계약 조건을 다시 확인하고 방침에 반영한다.

## 8. Google Drive 연결 해제

Google Drive 연결 해제는 계정 삭제와 별도로 할 수 있다.

1. ThreadMark의 설정에서 `Google Drive 연결 해제`를 선택한다.
2. ThreadMark는 저장된 Google OAuth token을 폐기하고 연결 상태를 해제한다.
3. 사용자는 [Google 계정의 서드 파티 연결 관리](https://myaccount.google.com/connections)에서도 ThreadMark의 접근 권한을 철회할 수 있다.
4. 연결 해제 후에도 사용자가 별도로 삭제하지 않은 Source와 Capture 메타데이터는 유지될 수 있지만, Drive 파일을 다시 열려면 재연결이 필요하다.
5. Google Drive에 저장된 원본 파일은 사용자의 소유이므로 연결 해제만으로 자동 삭제하지 않는다.

## 9. 계정 및 데이터 삭제 절차

### 앱에서 삭제

구현 예정 경로: `설정 → 계정 및 데이터 → 계정 삭제`

삭제 전 다음 선택을 명확히 표시한다.

- ThreadMark 계정, 프로필, Source, Capture, Project, 태그 및 연결 메타데이터 삭제
- 저장된 Google OAuth token 폐기 및 삭제
- Google Drive에 있는 원본 파일을 유지할지, ThreadMark가 만든 파일의 삭제를 별도로 요청할지 선택
- 되돌릴 수 없는 항목과 백업에서 제거되는 예상 기간 안내

재인증과 최종 확인을 거친 뒤 다음 순서로 처리한다.

1. 계정을 삭제 처리 중 상태로 전환하고 신규 쓰기를 차단한다.
2. Google OAuth 권한을 가능한 범위에서 폐기하고 저장된 token을 삭제한다.
3. 사용자 소유의 ThreadMark 데이터와 연결 메타데이터를 삭제한다.
4. 사용자가 명시적으로 선택한 경우에만 ThreadMark가 만든 Google Drive 파일 삭제를 요청한다.
5. Supabase Auth 계정을 삭제한다.
6. 삭제 완료 또는 부분 실패 항목을 사용자에게 안내한다.

### 이메일로 삭제 요청

다음 정보를 포함하여 `daesobi1@gmail.com`으로 요청할 수 있다.

- 제목: `ThreadMark 계정 삭제 요청`
- 가입한 이메일 주소
- 요청 범위: 계정 전체 삭제, 특정 데이터 삭제 또는 Google Drive 연결 해제

비밀번호, OAuth token, API key 또는 신분증 전체 사본은 이메일로 보내지 않는다. 추가 본인 확인이 필요한 경우 최소한의 안전한 절차를 별도로 안내한다.

## 10. 개인정보 보호조치

ThreadMark는 다음 보호조치를 적용하거나 구현할 예정이다.

- HTTPS를 통한 전송 암호화
- 사용자 데이터별 `owner_id`와 Supabase RLS 적용
- 승인 상태와 역할을 서버 및 RLS에서 재검증
- Supabase secret key와 외부 API 비밀값의 서버 전용 보관
- Google refresh token의 암호화 저장
- 최소 권한 Google Drive scope 사용
- 기본 비공개 설정과 명시적 공유 절차
- 관리자 승인·거절·정지 및 설정 변경 감사 로그
- 로그에서 token, API key, 원문 및 민감정보 제거
- 정기적인 의존성·권한·보안 설정 점검

## 11. 만 14세 미만 이용자

초기 ThreadMark는 만 14세 미만 아동을 대상으로 하지 않는다. 만 14세 미만 사용자를 대상으로 제공하려면 법정대리인 동의와 별도 보호 절차를 구현하고 이 방침을 개정한 뒤에만 허용한다.

## 12. 쿠키와 세션

ThreadMark는 로그인 상태 유지와 보안을 위해 필수 인증 쿠키 또는 유사한 세션 기술을 사용할 수 있다. 광고 추적이나 맞춤형 광고를 위한 쿠키는 사용하지 않는다. 분석 도구를 추가할 경우 수집 항목, 목적, 보유 기간 및 거부 방법을 사전에 고지한다.

## 13. 방침 변경

이 방침을 변경할 경우 시행일과 변경 내용을 서비스 안에서 알린다. 개인정보 또는 Google 사용자 데이터의 이용 목적이 실질적으로 달라지는 경우, 변경된 처리를 시작하기 전에 필요한 고지와 동의 절차를 진행한다.
